# TimeFit

Fit tasks into the free time you have. Each task has a duration, an optional due date, and a focus level.

Package: `com.TimeFitMNG.TimeFit`

Remote config: [N294.json](https://api2.blwsmartware.net/N294.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `tf_pack_1` … `tf_pack_10` | Consumable coins |
| `tf_remove_ads` | Non-consumable |
| `tf_pro` | Non-consumable, more than 8 open tasks |

Tasks and plans stay on the device. No account.
